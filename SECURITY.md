# Security policy

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability-reporting flow for this repository, or contact the
maintainers through a private GitHub channel.

Include the affected version, a minimal reproduction, impact, and any safe
mitigation you know. Please do not include live credentials, private endpoints,
or customer data.

This project treats authentication bypasses, secret disclosure, unsafe object
operations, command injection, and privilege-boundary failures as security
issues. Supported versions are the current release line on `main`.
